## 프로그래머스 1844. 게임 맵 최단거리

### 문제 설명

- n x m 크기의 게임 맵이 주어지며, 0은 벽, 1은 이동 가능한 길
- 캐릭터는 (1, 1)에서 출발해 동/서/남/북으로 한 칸씩 이동 가능
- 상대 팀 진영인 (n, m)까지 도달하는 최단 거리(칸 수)를 반환
- 도달할 수 없는 경우 -1 반환

### 문제 해결 방법

- 최단 거리 탐색이므로 **BFS(너비 우선 탐색)** 사용
- `dist[][]` 배열로 각 칸까지의 이동 횟수를 관리하며, 시작점을 1로 초기화
- 방문 여부는 `dist[nr][nc] == 0` 조건으로 확인 (0이면 미방문)
- BFS 완료 후 `dist[n-1][m-1]`이 0이면 도달 불가이므로 -1, 아니면 해당 값을 반환
