## 백준 11724. 연결 요소의 개수

### 문제 설명

- 방향 없는 그래프가 주어졌을 때, 연결 요소(Connected Component)의 개수를 구하는 문제
- 정점의 개수 N, 간선의 개수 M이 주어지고, M개의 간선 정보가 입력됨
- 서로 연결되어 있는 정점의 묶음 개수를 출력

### 문제 해결 방법

- 인접 리스트로 그래프를 구성하고, `visited[]` 배열로 방문 여부를 관리
- 모든 정점을 순회하며 방문하지 않은 정점에서 **BFS**를 수행
- BFS 1회 실행 = 연결된 정점을 모두 방문 = 연결 요소 1개 발견이므로, BFS 호출 횟수가 곧 연결 요소의 개수
