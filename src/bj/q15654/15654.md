## 백준 15663. N과 M (9)

### 문제 설명

- N개의 자연수 중에서 R개를 고른 수열을 모두 출력하는 문제
- 중복되는 수열은 출력하지 않으며, 사전 순으로 출력해야 함
- N개의 자연수는 모두 다른 수이며, 각 수는 한 번씩만 사용 가능

### 문제 해결 방법

- 사전 순 출력을 위해 입력받은 배열 A를 `Arrays.sort()`로 오름차순 정렬
- `selected` 리스트에 A 배열의 인덱스를 담아 관리하며, `selected.contains(i)`로 중복 선택 방지
- DFS 백트래킹으로 R개의 인덱스를 선택하고, `selected.size() == R`이 되면 인덱스를 통해 실제 값을 출력
